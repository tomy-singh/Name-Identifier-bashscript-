🧾 Name Identifier Bash Script

This project is a simple yet practical Bash script that identifies and extracts names from input data. It uses built-in shell utilities and pattern matching techniques to process text efficiently in a command-line environment.

🚀 Features
🔍 Detects and extracts names from user input or files
⚡ Fast and lightweight (no external dependencies)
🧠 Demonstrates core Bash scripting concepts
🛠 Easy to modify and extend
📚 What I Learned
Using variables and user input in Bash
Applying conditional statements and loops
Working with string manipulation and pattern matching
Writing clean and reusable shell scripts
